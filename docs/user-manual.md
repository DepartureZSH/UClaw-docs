# UClaw 用户使用手册

适用系统：Windows、macOS、Linux

这份手册面向普通用户，说明如何安装 UClaw、完成首次设置、开始 AI 对话、配置模型与联网搜索、连接外部渠道、创建定时任务，以及在移动盘或多台电脑之间使用。

UClaw 是 OpenClaw AI 智能体的桌面客户端，提供简洁直观的可视化界面——无需操作配置文件或命令行工具。

> **提示：** 本手册是各功能的快速综述。每个主题均有专属详情页，点击各节标题或文末链接可跳转查阅。

## 1. 安装 UClaw

从 [GitHub Releases](https://github.com/DepartureZSH/UClaw/releases) 下载对应系统的安装包或压缩包。

| 平台    | 安装方式                                                  |
| ------- | --------------------------------------------------------- |
| Windows | 下载 `win-x64.exe` 安装程序；如需便携安装，下载 `.zip`   |
| macOS   | 下载 `.app` 包，拖入**应用程序**文件夹后从该位置运行     |
| Linux   | 解压 tarball，必要时用 `chmod +x` 添加可执行权限         |

- Windows 可能显示"未知发布者"警告——点击**更多信息 → 仍要运行**即可。
- macOS 首次打开时，在**系统设置 → 隐私与安全性**中点击**仍要打开**。
- 请勿从 ExFAT 分区直接运行 macOS `.app`。

详细步骤：[安装指南](./installation.md)

## 2. 首次设置向导

首次启动时，UClaw 会运行五步设置向导：

1. 选择界面语言
2. 选择工作区文件夹（保存会话、配置和运行时）
3. 验证内置 Python 运行时和网关
4. 配置 AI 提供商（New API 端点与密钥）
5. 安装内置技能（文档处理、网络搜索、智能体工具）

工作区可放在 USB 驱动器或共享目录，实现跨设备无缝衔接。

详细步骤：[设置向导](./setup-wizard.md)

## 3. 聊天与智能体对话

在聊天页输入消息并发送。按 **Enter** 或点击**发送**；AI 生成期间点击**停止**可中断。

- 在输入框中输入 `@智能体名称` 可将消息路由到指定智能体。
- 每个智能体维护独立的对话历史，切换智能体时上下文不会混用。
- 点击**新建聊天**开始全新对话，旧会话保留在左侧列表中。

**触发网络搜索的提示词示例：**

```
请搜索今天最新的科技新闻，并附上来源。
```

```
搜索 [软件名称] 的最新版本，总结有哪些变化。不要依赖你的训练数据。
```

详细说明：[聊天](./features/chat.md)

## 4. 模型与 AI 提供商

模型页面管理 AI 提供商配置和 Token 使用历史。

- **AI 模型提供商**：显示当前提供商、模型 ID、密钥状态；点击**获取模型列表**刷新。
- **网络搜索**：UClaw 使用 New API 的 Kimi/Moonshot 模型提供联网搜索；点击**检测搜索模型**配置。
- **Token 使用历史**：按模型分类的 7 天 / 30 天滚动图表（本地读取，不外传）。

详细说明：[模型](./features/models.md) | [AI 提供商配置](./configuration/ai-providers.md)

## 5. 渠道（消息平台接入）

渠道页面将外部消息平台连接到 AI 智能体，传入消息自动由指定智能体处理。

| 渠道           | 连接方式   | 关键字段                              |
| -------------- | ---------- | ------------------------------------- |
| 微信           | 二维码     | 扫码，无需手动填写                    |
| WhatsApp       | 二维码     | 扫码，无需手动填写                    |
| Telegram       | 机器人令牌 | 机器人令牌、允许的用户 ID             |
| Discord        | 机器人令牌 | 机器人令牌、服务器 ID、频道 ID（可选）|
| 飞书 / Lark    | 应用凭据   | App ID、App Secret                    |
| 钉钉           | 应用凭据   | Client ID、Client Secret              |
| 企业微信       | 应用凭据   | Bot ID、App Secret                    |
| QQ 机器人      | 应用凭据   | App ID、Client Secret                 |

账号 ID 规则：只能使用小写字母、数字、`_`、`-`，最长 64 字符，必须以字母或数字开头。

保存渠道后如提示重启网关，按提示操作；重启完成后渠道才会激活。

详细说明：[渠道](./features/channels.md)

## 6. 定时任务

定时任务页自动按计划运行 AI 任务，可选将结果推送到渠道。

| 字段       | 说明                                        |
| ---------- | ------------------------------------------- |
| 任务名称   | 便于在列表中识别                            |
| 触发时间   | Cron 表达式（如 `0 8 * * 1-5`）或间隔（如 `1h`）|
| 提示词     | 每次运行时发送给智能体的内容                |
| 执行智能体 | 处理任务的智能体                            |
| 发送账号   | 外部推送时使用的渠道账号（可选）            |
| 接收目标   | 推送目标用户/群组（从已连接渠道自动发现）   |

详细说明：[定时任务](./features/cron.md)

## 7. 技能管理

技能页显示所有已安装技能，可启用/禁用，也可为需要 API 密钥的技能配置密钥。

**预置技能：**

| 类别       | 技能                                              | 需要密钥 |
| ---------- | ------------------------------------------------- | -------- |
| 文档处理   | `pdf`、`xlsx`、`docx`、`pptx`                     | 否       |
| 智能体工具 | `find-skills`、`self-improving-agent`             | 否       |
| 网络搜索   | `tavily-search`、`brave-web-search`               | 是       |

搜索技能需要分别配置 `TAVILY_API_KEY` 或 `BRAVE_SEARCH_API_KEY`，可在技能页的配置项中输入。

详细说明：[技能](./features/skills.md)

## 8. 设置与代理

**通用**：主题（浅色/深色/跟随系统）、界面语言、开机自动启动。

**网关**：查看连接状态（默认端口 `18789`）、打开日志文件夹。

**代理**：在**设置 → 网关 → 代理**配置代理服务器（如 `http://127.0.0.1:7890`）和绕过规则。保存后立即应用，无需手动重启。

**更新**：手动检查、自动检查或自动下载安装。

详细说明：[设置](./configuration/settings.md) | [代理服务器](./configuration/proxy.md)

## 9. USB 便携与跨系统使用

推荐使用双分区布局：APFS 分区存放 macOS `.app`，ExFAT 分区存放 Windows/Linux 版本和共享工作区。始终通过包内启动器（`Launch UClaw.command` / `Launch UClaw Windows.cmd`）启动，而非直接双击应用程序图标。

- 驱动器仍在同步或系统在扫描文件时，请勿立即启动。
- 慢速 U 盘会明显影响首次运行、解压和更新速度，推荐 USB 3.0+ 或便携 SSD。

详细说明：[便携 USB 模式](./advanced/portable-usb.md)

## 10. 常见问题速查

| 问题 | 解决方法 |
| ---- | -------- |
| 打开后进入设置向导 | 工作区路径不存在；重新选择正确的工作区文件夹 |
| 模型列表为空 | 确认网络正常，点击**获取模型列表**；或重新完成 AI 配置 |
| 联网搜索失败 | 确认模型页**网络搜索**显示已配置；点击**检测搜索模型**重新检测 |
| 网关启动慢 | 首次启动需准备运行环境；等待 30–60 秒；USB 驱动器慢时尤为明显 |
| 更新非常慢 | USB 写入大量小文件本身较慢；使用更快驱动器或在本地完成更新 |
| X 按钮不退出 | 点击 X 只会隐藏到系统托盘；在托盘图标菜单中选择**退出 UClaw** |

完整解答：[常见问题](./faq.md) | [故障排除](./troubleshooting.md)

## 11. 安全建议

- 不要公开包含 API 密钥或凭据的截图。
- USB 驱动器上的工作区包含完整对话历史——丢失时启用磁盘加密保护数据。
- 不要将不受信任的文件直接放入工作区。
- 联网搜索结果应查看来源；重要决策请核对原文。
