# UClaw 用户使用手册

适用版本：UClaw v0.2.11 及相近版本  
适用系统：Windows、macOS、Linux  
资料来源：`/Users/zsh/Documents/UClaw/docs/user-guide.md`

这份手册面向普通用户，说明如何安装 UClaw、完成首次设置、开始 AI 对话、配置模型与联网搜索、连接外部渠道、创建定时任务，以及在移动盘或多台电脑之间使用。

UClaw 是 OpenClaw AI Agent 的桌面客户端。你可以把它理解成一个本地 AI 工作台：它负责聊天界面、工作区、配置保存、Gateway 生命周期管理，并连接远程 AI API、联网搜索、工具和技能。

![UClaw 对话页](/img/uclaw/zh/chat.png)

## 1. 安装 UClaw

从 [GitHub Releases](https://github.com/DepartureZSH/UClaw/releases) 下载对应系统的安装包或压缩包。

### Windows

- 安装版通常下载 `win-x64.exe`，然后按安装向导完成。
- 移动盘版优先下载压缩包，解压到 U 盘或移动硬盘后，使用包内启动器或 `UClaw.exe`。
- 如果 Windows 提示未知发布者，请确认文件来自项目 Release 页面后再继续。

### macOS

- 下载 macOS 包后，建议把 `.app` 放到“应用程序”或 APFS 分区。
- 如果系统提示来自互联网或无法验证开发者，请在系统设置的安全性选项中允许打开。
- 数据和工作区可以放在移动盘，但不建议直接从 ExFAT 分区运行 `.app`。

### Linux

- 下载 Linux 包后解压。
- 如果无法启动，先给启动脚本或 AppImage 添加执行权限。
- 移动盘使用时，尽量保持挂载路径稳定。

## 2. 首次设置

第一次启动时，UClaw 会进入 Setup 设置向导：

1. 选择语言。
2. 选择工作区文件夹。
3. 检查本地运行环境和 Gateway。
4. 完成 New API 与联网搜索的一键配置或切换。
5. 进入主界面对话。

工作区会保存配置、会话和相关数据。跨电脑或移动盘使用时，建议把工作区放在容易识别的位置，例如移动盘中的 `workspace` 文件夹。

## 4. 对话和联网搜索

在对话页输入问题后发送即可。发送按钮变成停止按钮时，表示 AI 正在生成回复。

如果需要最新信息，请在问题中明确要求联网搜索，并要求附上来源。例如：

```text
请联网搜索今天的重点新闻，并附上来源。
```

```text
搜索后总结这个软件最近发布了哪些更新，不要只凭记忆回答。
```

UClaw 支持 Markdown 富文本渲染、多会话上下文，以及通过 `@agent` 将输入路由到指定 Agent。

## 5. 模型和 New API

UClaw 面向普通用户提供 New API 与联网搜索的一键配置或切换。普通用户不需要自行部署 New API，也不需要手动编辑 `openclaw.json`。

在模型页中：

- “AI 模型提供商”区域显示 New API 配置、当前模型 ID、API 密钥状态和“获取模型列表”按钮。
- “联网搜索 web-search”区域用于查看搜索模型、检测搜索配置，并从 New API 可用模型中选择 Kimi/Moonshot 搜索模型。
- 如果模型列表为空，先确认网络可用，再点击“获取模型列表”或重新执行一键配置。
- 如果普通对话可用但联网搜索失败，先检查 web-search 区域是否显示已配置，再尝试重新检测或重启 UClaw。

## 6. 频道配置

频道页支持多账号。手动填写账号 ID 时只能使用小写字母、数字、下划线和短横线，最长 64 位，并且必须以字母或数字开头。

| 频道 | 连接方式 | 需要填写的字段 | 说明 |
| --- | --- | --- | --- |
| 微信 WeChat | 扫码 | 不需要手写字段 | 点击生成二维码，用手机微信扫码并确认 |
| WhatsApp | 扫码 | 不需要手写字段 | 在手机 WhatsApp 的已关联设备中扫码 |
| Telegram | Bot Token | 机器人令牌、允许的用户 ID | 令牌来自 `@BotFather`；用户 ID 用于限制使用者 |
| Discord | Bot Token | 机器人令牌、服务器 ID、频道 ID（可选） | 频道 ID 可限制机器人只在指定频道工作 |
| 飞书 Feishu / Lark | 应用凭证 | 应用 ID、应用密钥 | 从飞书开放平台企业自建应用中获取 |
| 钉钉 DingTalk | 应用凭证 | Client ID / AppKey、Client Secret / AppSecret | 适用于钉钉 Stream 模式 |
| 企业微信 WeCom | 应用凭证 | 机器人 Bot ID、应用 Secret | 从企业微信管理后台或机器人配置中获取 |
| QQ Bot | 应用凭证 | App ID、Client Secret | 从 QQ 机器人开放平台获取 |

频道保存后，UClaw 可能会提示重启 Gateway。按提示重启即可。连接成功后，可以在频道页把账号绑定到某个 Agent；之后外部消息会交给对应 Agent 处理。

## 7. 定时任务

定时任务页用于创建日报、定时搜索、周期提醒和外部消息投递。常用字段包括：

- 任务名称：便于在列表中识别任务。
- 触发时间：按 Cron 规则或界面提供的周期配置执行。
- 提示词：任务执行时发送给 Agent 的内容。
- 执行 Agent：指定由哪个 Agent 处理任务。
- 发送账号：选择外部投递时使用哪个渠道账号发送。
- 接收目标：选择或填写消息投递目标。
- 启用状态：控制任务是否继续运行。

## 8. 技能管理

技能页用于查看和管理 OpenClaw 技能。UClaw 会展示技能名称、启用状态、来源位置、配置项和实际目录。

常见操作：

- 查看内置技能是否启用。
- 打开技能真实目录。
- 为需要 API Key 的搜索类技能填写配置。
- 排查技能缺失或配置错误。

## 9. 设置、代理和更新

设置页常用项包括：

- 主题：浅色、深色或跟随系统。
- 语言：切换界面语言。
- 开机自动启动：系统登录后自动打开 UClaw。
- 网关状态：查看 Gateway 是否已连接。
- 日志：打开应用日志文件夹。
- 代理服务器：公司网、校园网或本地代理环境下可填写 `http://127.0.0.1:7890`。
- 绕过规则：不走代理的主机，支持用分号、逗号或换行分隔。
- 检查更新：手动检查 GitHub Release 中的新版本。

保存代理设置后，UClaw 会重新应用 Electron 网络层并按需要重启 Gateway。

## 10. 移动盘和跨系统使用

移动盘使用的核心原则是：用包内启动器打开应用，让数据目录和工作区都跟着移动盘走。

推荐做法：

- Windows：解压移动盘包到 U 盘或移动硬盘，优先使用包内启动器或 `UClaw.exe`。
- macOS：应用放 APFS 分区或本机应用目录，数据和工作区放共享分区；优先使用 `Launch UClaw.command`。
- Linux：解压后运行包内启动脚本；如果无法启动，先添加执行权限。

不要在拷贝未完成、移动盘正在同步或系统还在扫描文件时立即启动。慢速 U 盘会明显拖慢首次运行、解压和更新。

## 11. 常见问题

### 为什么打开后又进入 Setup？

常见原因是第一次在这台电脑安装、之前保存的工作区路径不存在、移动硬盘盘符变化，或者你删除了工作区。重新选择正确工作区即可。

### 为什么模型列表为空？

先确认 New API 一键配置是否完成，再检查网络是否能访问远程服务。之后回到模型页点击“获取模型列表”。

### 为什么普通对话可以，联网搜索失败？

先确认 web-search 区域显示已配置，并重新检测搜索模型。如果仍失败，重启 UClaw 后再试；必要时打开日志并反馈错误信息。

### 为什么 Gateway 启动慢？

首次启动会准备本地运行环境并检查组件。慢速移动盘、老电脑或安全软件扫描都可能拖慢启动。

### 为什么更新很慢？

Windows 安装包、压缩包和运行时包含较多小文件。慢速 U 盘写入小文件会非常慢，建议使用速度更好的 U 盘或移动 SSD。

## 12. 安全建议

- 不要公开服务配置、访问凭证或包含敏感信息的设置页面截图。
- 移动盘丢失时，工作区里的配置和聊天记录也可能泄露，建议重要设备开启磁盘加密。
- 不要把不可信来源的文件直接放进工作区。
- 联网搜索得到的信息要看来源。重要决策不要只听 AI 总结，最好打开来源页面核对原文、日期和上下文。
