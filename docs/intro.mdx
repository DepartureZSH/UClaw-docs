# UClaw 文档中心

这里是 UClaw 文档站，面向普通用户和开发者整理安装、使用、便携版制作和发布维护资料。

UClaw 是 OpenClaw AI Agent 的跨平台桌面客户端。它将 OpenClaw 的命令行智能体编排能力封装为图形化体验，让用户可以通过桌面应用完成模型服务配置、智能体对话、多渠道接入、定时任务、技能管理和诊断维护。

## 文档入口

- [用户使用手册](./user-manual)：面向普通用户，覆盖安装、首次启动、聊天、模型、联网搜索、渠道、定时任务、技能和移动盘使用。
- [开发者便携版制作手册](./developer-portable-manual)：面向开发者，覆盖便携版目标、打包命令、启动器要求、隔离验证和发布检查。
- [UClaw 产品页](/uclaw)：了解 UClaw 的产品能力、架构和使用场景。
